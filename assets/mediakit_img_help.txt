image — 图像处理，涵盖图像增强、内容理解和 AI 编辑等能力。

Available commands:
- add-image-watermark    为图片添加图文明水印，适用于版权标识与素材分发防盗链场景。
  查看详情: mediakit-cli image add-image-watermark --help
- adjust-image-color    对输入图像的亮度、对比度和饱和度进行调整，支持调亮、调暗、增强对比度、减弱对比度、增强饱和度、减弱饱和度共 6 种快速调整效果。适用于素材基础优化、统一内容视觉风格、营造庄重、复古等特殊氛围等场景。
  查看详情: mediakit-cli image adjust-image-color --help
- compress-image    支持一站式图像体积优化，覆盖压缩质量、文件体积上限、输出格式转换和 PNG 瘦身；适用于用户上传图片前的体积治理；适用于网站与 App 的图片分发加载优化；适用于 AIGC 与多模态模型的媒体预处理。
  查看详情: mediakit-cli image compress-image --help
- crop-image    对输入图像进行多模式裁剪，可执行方向裁剪、定向裁剪、自定义裁剪或内切圆裁剪，适用于多端尺寸适配、主体保留、商品图去边和指定区域截取。
  查看详情: mediakit-cli image crop-image --help
- enhance-image    基于图像内容理解进行智能决策，提升图片的分辨率、清晰度与色彩表现。
  查看详情: mediakit-cli image enhance-image --help
- erase-image    可按不同场景控制自动检测并擦除图片中的文字或常见图标，擦除后的区域通过智能填充技术进行修复，修复后的区域与背景自然融合。
  查看详情: mediakit-cli image erase-image --help
- evaluate-image-quality    用于图像画质评估，对输入图片进行主客观画质和美学评分，适用于质量监控、低质图筛查、内容审核、推荐排序和训练数据清洗。
  查看详情: mediakit-cli image evaluate-image-quality --help
- face-blur-image    自动检测图片中的所有人脸区域并进行马赛克处理，用于一键保护图片中的人脸隐私。支持社交平台内容审核、街景或监控画面脱敏、新闻媒体素材处理以及 AI 训练数据集脱敏等批量人脸隐私保护场景。
  查看详情: mediakit-cli image face-blur-image --help
- flip-image    支持对单张图片执行水平或竖直翻转。
  查看详情: mediakit-cli image flip-image --help
- gaussian-blur-image    用于图像高斯模糊；通过设定模糊强度快速对图片进行模糊处理，适用于隐私信息弱化、背景氛围化、生成预览图及封面背景等场景。
  查看详情: mediakit-cli image gaussian-blur-image --help
- image-ocr    用于通用印刷体文字识别（OCR），识别图片中的简体中文和英文，并提供文本块位置坐标与置信度参考。
  查看详情: mediakit-cli image image-ocr --help
- invert-image    用于图像负片，对输入图像执行负片（反相）效果，将图像的明暗关系与颜色映射为原图的相反效果，即明暗反转、色彩转为补色。
  查看详情: mediakit-cli image invert-image --help
- mosaic-image    支持对整张图像或指定矩形区域进行马赛克打码，可调整像素格形状与大小。支持用于遮挡人脸、证件信息、车牌、聊天记录等敏感内容。
  查看详情: mediakit-cli image mosaic-image --help
- probe-image-metadata    支持查询 metadata、avghue、alpha、blurhash 四种图像信息。
  查看详情: mediakit-cli image probe-image-metadata --help
- remove-image-background    自动识别并保留图像主体，移除背景后生成背景透明的图片，用于图像背景移除（抠图）。
  查看详情: mediakit-cli image remove-image-background --help
- resize-image    用于图像缩放，支持按指定宽高精确缩放，也可按长边、短边或等比模式缩放，适用于多端素材适配、封面与缩略图生成及批量图片预处理。
  查看详情: mediakit-cli image resize-image --help
- rotate-image    通过设置旋转角度和旋转背景样式对图片进行旋转处理，适用于图片方向校正、创意编辑和批量图像处理。
  查看详情: mediakit-cli image rotate-image --help
- round-corner-image    为图片四角快速添加正圆或椭圆圆角，适用于头像、卡片、电商主图等常见视觉编辑场景。
  查看详情: mediakit-cli image round-corner-image --help
- sharpen-image    用于图像锐化，通过对输入图像进行锐化处理，有效增强图像的边缘细节与整体清晰度。适用于电商素材优化、UGC 画质增强、封面海报二创等场景。
  查看详情: mediakit-cli image sharpen-image --help
- slim-image    集智瘦身通过 AI 大幅缩小图片体积，修复毛刺、彩噪和块效应等问题，增强图像边缘与纹理细节，输出更轻量且更清晰的图片。
  查看详情: mediakit-cli image slim-image --help
- smart-crop-image    自动识别图像中的主体人脸区域，并适配指定尺寸进行裁剪；支持普通人脸和动漫人脸场景。未识别到人脸时，可按预设的降级策略输出结果。
  查看详情: mediakit-cli image smart-crop-image --help

Usage:
  mediakit-cli image [flags]
  mediakit-cli image [command]

Flags:
  -h, --help   help for image

Use "mediakit-cli image [command] --help" for more information about a command.
